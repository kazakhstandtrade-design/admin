Архитектура анонимности
После подтверждения права голоса пользователь получает одноразовый токен. При отправке бюллетень сохраняется отдельно от данных личности. В объекте anonymous_ballots отсутствуют ИИН, email и данные пользовательского аккаунта. Реестр voted_iins используется отдельно для контроля правила «один ИИН — один голос». В реальной системе эти компоненты должны находиться на сервере и быть защищены от изменения пользователем.
ВНИМАНИЕ: текущая версия является демонстрационным фронтенд-прототипом. Данные хранятся в localStorage браузера и не являются защищённым хранилищем. Пользователь технически может изменить эти данные через инструменты разработчика. Для реального голосования необходим сервер, база данных, криптографическая инфраструктура и контроль целостности данных.
